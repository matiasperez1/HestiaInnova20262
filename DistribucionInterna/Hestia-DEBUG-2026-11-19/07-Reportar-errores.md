# Reportar errores al equipo

Usa el canal privado que acuerde el Grupo 28. Envía un reporte por problema. Para las llamadas, indica si Hestia era el marcador, si estaba activada la identificación, si Recientes estaba habilitado y si Android mostró la pantalla de llamada o una notificación.

```text
Título breve
Versión de Hestia y primeros 12 caracteres del SHA-256 del APK
Modelo de teléfono y versión de Android
Pantalla o función
Pasos para reproducir
Resultado esperado
Resultado observado y mensaje exacto, ocultando datos privados
Frecuencia y hora aproximada
Permisos, roles y estado de Wi-Fi/datos relevantes
```

Si compartes una captura, cubre números completos, nombres de contactos, direcciones de correo e identificadores personales. Usa etiquetas como **teléfono de prueba A**. Evita adjuntar historiales completos, reportes de diagnóstico del sistema, tokens o archivos de configuración. Si Android bloquea la instalación, adjunta el mensaje del instalador con los datos privados ocultos.

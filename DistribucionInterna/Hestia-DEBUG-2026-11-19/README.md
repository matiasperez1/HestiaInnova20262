# Hestia DEBUG para el equipo

Edición interna del 19 de noviembre de 2026. Hestia ayuda a adultos mayores a reconocer llamadas sospechosas, guardar reportes personales y practicar medidas de prevención.

Esta compilación permite evaluar **Resumen, Teléfono, Aprender y Familia**. Se puede probar el marcador, la agenda autorizada y los reportes personales con los datos de cada teléfono. Para probar con una instalación nueva, usa **Continuar sin cuenta** y **Continuar sin Gmail** durante la configuración inicial.

## Compartir mediante Google Drive

Sube únicamente esta carpeta a una ubicación de Drive con acceso **Restringido**. Agrega a tus compañeros como **Lectores** y permite que descarguen el APK. Conserva `SHA256SUMS.txt` junto al APK para que puedan verificar la misma descarga. [Ayuda de Google Drive](https://support.google.com/drive/answer/7166529?hl=es-419)

La carpeta contiene la app y las guías del equipo. Para leerlas localmente, descarga la carpeta y abre los archivos `.md` con un editor de texto o visor Markdown.
